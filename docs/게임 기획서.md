# 유니티 기반 2D 주식 게임 기획서 초안

버전 0.11 · 작성일 2026년 11월 25일

아침에는 알바 미니게임으로 투자금을 벌고, 저녁에는 플레이어가 직접 차트를 읽고 매매하는 2D 성장 게임이다. 미소녀 주인공의 일상과 투자 상황 사이에서 나오는 갭모에를 즐기며, 벌어들인 돈으로 집과 생활 환경을 바꾸어 성공을 체감한다.

이 기획의 중심은 **직접 판단하는 투자, 눈에 보이는 생활의 변화, 밤마다 모으는 캐릭터 컷신**이다. 캐릭터 능력치가 플레이어 대신 투자하거나 정답을 알려주는 방식은 사용하지 않는다. 자금이 부족할 때는 대출로 재도전할 수 있으며, 투자 성공과 강제 청산을 포함한 플레이 기록에 따라 밤 종료 컷신이 달라진다.

캐릭터 설정과 메인 스토리는 [캐릭터 및 스토리 초안](캐릭터%20및%20스토리%20초안.md)에서 별도로 관리한다.

## 핵심 재미

플레이어는 알바로 번 돈의 무게를 알고 투자한다. 차트를 보고 매수한 뒤 수익을 확정하면, 계좌의 숫자뿐 아니라 책상과 방이 달라진다. 큰 손실을 입었을 때도 다음 날 알바로 다시 시작할 수 있다.

성장에는 두 가지 선택이 있다. 돈을 계좌에 남겨 다음 거래에 사용할 수도 있고, 일부를 써서 더 좋은 생활을 얻을 수도 있다. 집에 돈을 쓴 선택도 의미 있는 성공으로 기록한다.

컷신 수집은 자산 성장과 함께 장기 목표가 된다. 큰 수익을 낸 밤, 청산을 겪은 밤, 빚을 모두 갚은 밤이 서로 다른 캐릭터 장면으로 남는다. 손실에도 새로운 장면을 발견할 수 있지만, 실패 장면 수집 때문에 다음 플레이가 막히지는 않게 한다.

## 하루의 진행

**집에서 하루 시작 → 아침 편의점 알바 → 저녁 자금 준비와 매매 → 결산과 상환 → 조건에 따른 컷신 → 집과 장비 꾸미기 → 다음 날**

| 단계 | 플레이어 행동 | 역할 |
| --- | --- | --- |
| 집 | 오늘의 목표와 자금 확인 | 이전에 이룬 성장을 보여주고 다음 목표 제시 |
| 아침 알바 | 짧은 미니게임 수행 | 투자금 확보와 주인공의 일상 표현 |
| 저녁 거래 | 컴퓨터 바탕화면에서 앱 실행, 정보 탐색, 필요하면 대출 선택, 직접 매매 | 게임의 핵심 판단과 긴장감 |
| 결산 | 실현 손익·보유 자산·부채 확인, 상환 선택 | 결과를 이해하고 다음 날 계획 |
| 밤 종료 컷신 | 조건에 맞는 장면 감상과 수집 | 투자 결과를 캐릭터의 이야기로 전환 |
| 생활 개선 | 가구·장비 구매와 배치, 이사 | 수익을 시각적 보상으로 전환 |

하루는 우선 6~10분을 목표로 잡는다. 알바는 1~2분, 거래는 3~5분, 나머지는 결산과 생활 이벤트에 배분한다. 뉴스·커뮤니티를 읽는 시간은 조정이 필요한 추가 분량이다. 메뉴와 대화에서는 시장 시간이 멈추고, 거래 중에는 모든 종목의 시간이 함께 흐른다. 종목을 바꾸어도 가격 진행은 초기화되지 않는다.

첫 시제품에서는 매일 거래 세션이 열리는 가상 시장을 사용한다. 정식 버전에서도 코인 등을 저녁 세션에 맞추어 표현하며, 플레이어가 알바나 꾸미기를 하는 동안 보이지 않는 거래 시간을 진행시키지 않는다.

## 아트 방향과 컨셉 이미지

일러스트와 이미지 에셋 제작은 [에셋 생성 규칙](에셋%20생성%20규칙.md)을 따른다. FHD 기준 화면 설계, 배경·컷신 4K 원본 목표, 종류별 해상도, 분리 제작과 출처 기록 기준을 해당 문서에 정리한다.

윤서하의 첫 [캐릭터 시트 v001](characters/yoon_seoha_character_sheet_v001.md)은 사용자 제공 인물 이미지의 얼굴·머리·실내복을 기준으로 만든 컨셉 검토 자료다. 전신 3면·표정 4종·의상·색상표를 포함하며, 실제 생성 크기는 1672×941이다. 외형의 최종 승인이나 게임용 투명 입상·표정 분리 완료를 의미하지 않는다.

캐릭터 일러스트, 집과 편의점 배경, 컷신, 이후 생성할 에셋은 밝고 부드러운 파스텔 톤으로 통일한다. 블루 아카이브는 색감과 분위기의 참고 대상으로 삼고, 캐릭터·로고·아이콘·화면 배치는 이 게임에 맞게 독자적으로 설계한다.

색상 제안은 우윳빛 흰색과 옅은 하늘색을 바탕으로 민트·연보라·연분홍을 보조색으로 쓰는 방향이다. 텍스트와 차트 눈금은 짙은 청회색으로 대비를 확보한다. 매수·매도·손실·경고는 배경색만으로 구분하지 않고 글자와 기호를 함께 사용한다. 밤 배경도 전체를 짙은 남색으로 덮기보다, 부드러운 푸른 그림자와 따뜻한 실내 조명으로 시간을 표현한다.

사용자 제공 [초기 투자 화면 컨셉](concepts/investment-screen-v1.png)은 주인공의 투자 반응, 방과 컴퓨터의 관계, 필요한 기능을 파악하는 참고 이미지로 보관한다. 이미지 안의 캐릭터 외형·남색 중심 색상·숫자·화면 배치가 최종 확정된 것은 아니다.

현재 이미지의 투자 창에는 차트와 주문 외에 뉴스·커뮤니티·대출·상환이 함께 들어 있고, 바깥에는 식사·수집·목표까지 상시 표시되어 있다. 이후 시안은 **컴퓨터 바탕화면과 역할별 앱**으로 다시 구성한다. 기능은 유지하면서 화면마다 집중할 행동을 줄인다.

## 컴퓨터와 가상 OS

### 집에서 바탕화면으로 진입

집의 책상이나 컴퓨터를 클릭하면 컴퓨터 화면 중심으로 전환하고 가상 OS 바탕화면을 보여준다. 바탕화면의 앱 아이콘을 클릭해 증권 앱이나 인터넷 브라우저를 연다. 게임 진행을 위한 가상 컴퓨터이며, 바탕화면 배경·아이콘·작업 표시줄·창 제목줄을 이 게임의 디자인으로 만든다.

기본 흐름은 **집 → 컴퓨터 바탕화면 → 앱 실행 → 필요한 행동 → 최소화 또는 닫기 → 다른 앱 선택**이다. 특정 앱을 처음부터 강제로 펼치지 않는다. 작업 표시줄에서도 실행 중인 앱을 다시 선택할 수 있게 한다.

### 앱별 역할

| 앱 또는 기능 | 담을 내용 | 진입 방식 |
| --- | --- | --- |
| 증권 앱 | 종목 목록, 차트·거래량, 현재가, 보유 현황, 주문·거래 내역, 거래 가능 현금 | 바탕화면 아이콘 |
| 인터넷 브라우저 | 가상 뉴스 사이트와 커뮤니티 사이트, 기사·게시글·댓글 | 바탕화면 아이콘, 브라우저 홈의 즐겨찾기 |
| 금융 앱 | 대출 한도·이자·만기, 대출 실행, 상환과 부채 내역 | 별도 바탕화면 아이콘으로 분리하는 안 |
| 밤의 기록 | 해금한 컷신, 미감상 표시, 조건 힌트와 다시 보기 | 앨범 앱으로 제공하는 안, 집의 앨범과 같은 기록 사용 |
| 설정 | 소리, 표시, 본 컷신 자동 넘기기 등 | OS 메뉴 또는 작은 설정 아이콘 |
| 컴퓨터 테마 | 해금한 배경화면·창 테마·아이콘 외형 선택 | OS 설정 안에 두는 안 |

뉴스와 커뮤니티는 증권 앱 안의 하단 패널이 아닌 브라우저 안의 별도 사이트다. 브라우저 홈에서 원하는 사이트로 이동하고, 탭으로 뉴스와 커뮤니티를 오갈 수 있게 한다. 실제 외부 웹을 여는 기능은 필요하지 않다. 코인과 선물 앱 분리 여부는 각 투자 시스템을 구체화할 때 정한다.

증권 앱에는 차트 판단과 주문에 필요한 정보만 배치한다. 뉴스 본문·커뮤니티 피드·대출 실행·식사·가구 목표·컷신 수집률은 증권 창에 상시 나열하지 않는다. 기사에서 관련 종목을 누르면 증권 앱의 해당 종목으로 전환할 수 있다.

### 창과 화면 밀도

초기 구성안은 **큰 앱 창 하나를 전면에 표시**하는 방식이다. 앱 안에서도 거래·보유·내역처럼 필요한 페이지를 선택한다. 여러 앱을 겹쳐 모두 펼치거나 차트와 사이트를 항상 분할 표시하는 구성은 초기 기본 화면으로 삼지 않는다. 자유로운 창 크기 조절과 복잡한 창 배치는 별도 검토로 둔다.

최소화는 앱을 작업 표시줄로 보내고, 닫기는 창을 닫는다. 어느 경우에도 보유 자산·주문 기록·시장 상태가 초기화되지 않는다. 앱을 다시 열면 선택한 종목과 읽던 페이지를 복원한다. 창을 닫는 행동을 매도·상환·밤 거래 종료로 취급하지 않는다.

공통 표시에는 게임 내 날짜·시각, 작은 컨디션 아이콘, 거래 진행·일시정지 상태만 우선 배치한다. 컨디션을 누르면 상세 게이지와 회복 행동을 확인하는 작은 패널을 여는 안으로 잡는다. 식사·간식·음료는 이 패널이나 집의 생활 상호작용에서 선택한다. 큰 회복 버튼 세 개를 모든 앱 옆에 고정하지 않는다.

주인공과 방은 집 화면에서 충분히 보여주고, 컴퓨터 사용 중에는 작은 초상화·짧은 반응·필요한 순간의 연출로 존재감을 유지하는 안을 제안한다. 큰 캐릭터 패널을 항상 고정해 차트 영역을 줄이지 않는다. 새로운 컷신과 목표 달성은 작은 알림으로 안내하고 상세 내용은 해당 화면에서 확인한다.

### 앱 전환과 거래 시간

기존의 정보 읽기 시간 정지 규칙을 유지한다. 증권 앱의 거래 화면이 전면이고 거래를 진행하는 동안 시장 시계가 흐른다. 브라우저·금융 앱·앨범·설정·회복 패널을 열거나 바탕화면으로 돌아가면 시장과 컨디션 소모를 함께 멈추는 안으로 통일한다. 창이 뒤에 열려 있다는 이유로 몰래 시장이 진행되지는 않는다.

증권 앱으로 돌아와 거래 재개를 누르면 같은 시점에서 이어진다. 화면의 정지 표시와 재개 버튼으로 현재 상태를 알린다. 앱 실행·최소화·종료만으로 미래 정보가 공개되거나 컨디션이 회복되지는 않는다. 이미 발생했거나 예정된 컨디션 효과도 기존 규칙대로 보존한다.

컴퓨터에서 집으로 돌아가는 동작과 그날 거래를 끝내는 동작은 구분한다. OS 메뉴의 「오늘 거래 종료」를 선택하면 보유 현물과 부채를 확인하고 결산·상환·컷신 흐름으로 들어간다. 증권 앱의 닫기 버튼이나 컴퓨터 나가기 버튼은 결산을 실행하지 않는다.

### 컴퓨터 성장 보상

집에서 구입한 노트북·모니터·책상은 방의 외형을 바꾼다. 거래 성과로 해금하는 UI 보상은 OS 배경화면, 창 테마, 작업 표시줄, 앱 아이콘, 소리로 확장한다. 증권 앱 테마도 같은 색상 체계에 맞춘다. 새 장비와 테마를 얻어도 필수 앱·기본 거래 기능은 처음부터 사용할 수 있다.

## 플레이어가 직접 판단하는 거래

### 차트와 주문

거래 화면에는 캔들 차트, 거래량, 현재 가격, 현금, 보유 수량, 평균 매입 가격, 평가 손익을 표시한다. 플레이어는 종목을 고르고 수량을 정해 직접 사고판다. 주문 전에는 사용할 금액과 거래 비용을 확인할 수 있다.

초기 주문 방식은 시장가 매수와 매도로 제한한다. 차트 확대와 축소, 과거 구간 이동, 보유 가격선 표시를 제공한다. 이동평균선 같은 보조 지표, 지정가 주문, 가격 알림은 핵심 조작을 검증한 뒤 검토한다.

주인공은 거래를 자동 실행하거나 매수·매도 신호를 주지 않는다. 튜토리얼은 차트와 주문 화면을 읽는 법을 설명하고, 어떤 모양의 차트도 수익을 보장하는 정답으로 제시하지 않는다.

### 시장의 움직임

가격은 추세, 변동성, 거래량, 이벤트를 함께 고려하는 가상 시장 규칙으로 생성한다. 회사·종목 이름은 고정하고, 새 회차마다 사건 배정·추세·등락 폭·발생 시점을 난수로 구성한다. 뉴스는 해당 회차에 실제 배정된 사건과 연결한다. 같은 캔들과 거래량 데이터가 화면과 체결 계산에 공통으로 사용되어야 한다.

플레이어가 관찰하고 가설을 세울 수 있는 상승 흐름, 하락 흐름, 횡보, 급격한 변동을 구성한다. 특정 패턴 다음에 항상 같은 결과가 나오지 않도록 하며, 플레이어가 매수했다는 이유로 가격 방향을 불리하게 바꾸지 않는다.

뉴스와 커뮤니티는 주식 판단을 위한 주요 정보원이다. 사건의 진위, 공개 시점, 가격에 반영된 정도가 서로 다르며, 플레이어가 정보와 차트를 함께 해석한다. 알바 중의 대화와 주변 인물의 제보는 스토리 확장 때 검토한다.

진행 중인 캔들과 완료된 캔들을 구분한다. 보유 현물은 다음 날로 넘길 수 있고, 첫 시제품에서는 세션 사이 가격을 고정해 다음 거래 세션이 같은 가격에서 이어지게 한다. 저장과 불러오기는 자금·주문·시장 상태를 함께 보존한다.

### 투자 대상별 확장 방향

| 대상 | 게임에서 줄 경험 | 도입 순서 |
| --- | --- | --- |
| 주식 | 여러 가상 기업의 차트를 비교하고 자금을 배분 | 첫 시제품 |
| 코인 | 더 큰 변동과 빠른 상황 변화 속에서 진입·청산 판단 | 주식 거래의 재미 검증 후 |
| 선물 | 상승·하락 방향 선택과 제한된 자금의 손실 관리 | 가장 나중에 추가 |

선물은 게임용 단순화 규칙을 별도로 설계한다. 투입 금액과 손실 한도를 명확히 표시하고, 한 거래의 손실이 그 거래에 배정한 금액을 넘지 않도록 한다. 청산 기준, 계산, 튜토리얼까지 갖춘 뒤 도입한다.

컷신 조건에서 말하는 청산은 **선물 포지션의 강제 청산**을 뜻한다. 플레이어가 직접 주식을 매도하거나 선물 포지션을 정리하는 행위와 구분한다. 강제 청산 순간에는 짧은 표정·효과음으로 반응하고, 수집용 본편 컷신은 그날 밤 거래를 끝냈을 때 재생한다.

## 주식 투자와 정보 탐색

주식에서는 **정보가 얼마나 믿을 만한지, 얼마나 일찍 나왔는지, 지금 가격에 얼마나 반영됐는지**를 함께 판단한다. 플레이어는 뉴스와 커뮤니티를 비교하고 차트를 살핀 뒤 매수·보유·매도·관망을 선택한다.

뉴스와 커뮤니티는 게임 안의 가상 사이트다. 실제 웹이나 실제 투자 정보를 연결하지 않는다. 아래 내용은 현실 시장의 통계나 규칙이 아닌 게임 내 설계다.

### 두 정보원의 차이

| 구분 | 뉴스 사이트 | 커뮤니티 사이트 |
| --- | --- | --- |
| 게시 내용 | 기업 발표, 실적, 계약, 개발 성과 등 확인된 사실 중심 | 종목 추천, 소문, 경험담, 일상, 유머, 댓글 논쟁 |
| 사실 신뢰도 | 높음 | 낮음 |
| 정보 시점 | 널리 공개되었거나 시장이 먼저 반응한 뒤인 경우가 많음 | 공식 발표 전에 단서가 나오기도 함 |
| 진입 시 가격 | 이미 상승한 상태일 가능성이 높음 | 아직 움직이지 않았거나 소문에만 반응한 상태도 있음 |
| 상승 기회 | 추가 상승은 상대적으로 작거나 없을 수 있음 | 실제 호재를 일찍 잡으면 더 큰 상승 기회 |
| 주요 위험 | 좋은 소식이어도 비싼 가격에 뒤늦게 진입 | 거짓 정보, 과장, 오해, 일시적 급등 후 하락 |
| 플레이어의 질문 | 사실은 확인됐는데 지금도 살 만한가 | 이 말을 믿을 근거가 있고 아직 이른가 |

뉴스의 신뢰도는 보도한 사실이 맞는 정도다. 그 종목이 앞으로 오를 확률과 같은 수치가 아니다. 커뮤니티에서는 사실 적중과 이후 가격 상승을 별도로 다룬다. 소문이 사실이어도 이미 가격에 반영됐거나 기대보다 작은 성과라면 추가 상승이 약할 수 있다.

사용자 방향에 맞춰 커뮤니티 추천이 이후 상승으로 이어지는 경우는 적게 구성한다. 다만 실제 호재가 있고 가격 반영이 적었던 소문에 일찍 진입했다면, 같은 사건의 공식 뉴스 이후에 진입한 경우보다 큰 수익 기회를 제공한다. 모든 커뮤니티 성공 거래가 모든 뉴스 거래보다 큰 수익을 내는 고정 규칙은 아니다.

### 뉴스 사이트

기사 목록에는 제목, 매체명, 게임 내 게시 일시, 관련 기업·업종을 표시한다. 본문은 무엇이 확정됐는지와 아직 남은 단계를 짧게 설명한다. 관련 종목을 누르면 차트로 이동하고, 차트에는 해당 기사의 게시 시점 표시를 선택해서 볼 수 있게 한다.

기사 예시: **“모모바이오, 신약 후보 물질 시험 성과 발표”**. 본문은 시험 성과 발표가 있었다는 사실을 전달하고, 추가 시험이나 상용화 여부는 별개임을 알린다. 제목에 쓰인 성공의 범위와 실제 사업 성과를 구분할 수 있게 한다.

호재 뉴스 다음에도 추가 상승, 횡보, 하락이 모두 가능하다. 가격이 충분히 반영되지 않은 기사도 일부 둬 뉴스를 항상 늦은 정보로 무시하는 고정 공략을 막는다. 악재 뉴스와 시장·업종 기사도 포함해 보유 종목을 계속 들고 갈지 판단하는 데 활용한다.

선반영은 “반영 완료”라는 정답 표시 대신, 기사 게시 시점과 그 전후의 가격·거래량으로 관찰하게 한다. 예를 들어 기사를 처음 열었을 때 이미 차트가 크게 상승했다면, 사실의 확인과 진입 가격 사이에서 고민할 수 있다.

### 커뮤니티 사이트

커뮤니티에는 주식 이야기와 일상 이야기가 섞여 있다. 모든 글이 투자 단서가 되지 않으며, 유머·잡담도 캐릭터와 세계관을 보여주는 콘텐츠로 사용한다. 초반에는 짧은 글 위주로 구성해 긴 글 탐색이 매일의 의무가 되지 않게 한다.

| 게시글 종류 | 예시 | 역할 |
| --- | --- | --- |
| 직접적인 종목 추천 | “모모바이오 이번 주에 간다. 나만 믿어라.” | 강한 확신과 부족한 근거의 대비 |
| 개발·계약 소문 | “여기 개발 성공했다던데 발표만 남았대.” | 사실일 수도 있는 이른 정보 |
| 일상 속 관찰 | “요즘 우리 동네에서 별빛음료 신제품 계속 품절임.” | 기업 상황과 연결할 수 있지만 범위가 좁은 단서 |
| 뉴스 재게시 | “방금 기사 떴다. 지금이라도 타야 하나?” | 오래된 정보를 새 정보로 오해할 가능성 |
| 반박과 검증 | “그 사진 작년 행사 때 거야.” | 다른 글과 대조할 수 있는 근거 |
| 일상과 유머 | “알바 끝났는데 내 종목은 아직 야근하네.” | 커뮤니티 분위기와 가벼운 재미 |

게시글에는 닉네임, 게시 일시, 관련 종목 태그, 본문, 추천·조회, 일부 댓글을 표시한다. 게시글 시점과 인용 자료의 원래 시점을 구분한다. 같은 소문을 여러 번 퍼 나른 글은 독립적인 여러 증거가 되지 않는다.

추천 수와 자신감 있는 문체는 진실 판정 표시가 아니다. 진짜 단서가 묻히기도 하고 거짓 소문이 인기글이 되기도 한다. 작성자의 과거 글과 후속 해명을 일부 볼 수 있게 해 플레이어가 신뢰를 판단하게 하되, 항상 맞는 닉네임이나 정답 문구는 만들지 않는다.

정보의 진위를 완벽하게 맞힐 수는 없어도, 게시 시각·자료 출처·다른 글의 반박·실제 가격 반응으로 더 나은 판단을 할 수 있어야 한다. 단서 없는 거짓말과 무작위 결과만으로 구성하지 않는다.

### 하나의 사건이 정보와 차트로 이어지는 과정

기업 사건을 먼저 정하고, 그 사건에 대한 소문·공식 발표·정정·가격 반응을 연결한다. 게시물을 열거나 매수한 순간에 소문의 진위를 새로 추첨하지 않는다. 같은 시장 진행에서 사건 결과는 플레이어의 행동과 독립적으로 유지한다.

사건에는 관련 종목, 실제 사실, 발생 단계, 공개 일정, 퍼지는 소문, 시장의 기존 기대, 가격에 미칠 영향의 범위를 정한다. 차트에는 사건의 영향과 일반적인 변동을 함께 반영한다. 플레이어에게 미래의 정확한 확률이나 목표 가격을 공개하지 않는다.

사건의 실제 결과와 종목 배정은 회차별 무작위 구성이다. 사전 작성한 글이 사건 결과를 결정하지 않는다. 먼저 해당 회차의 사건을 정하고, 그 사실과 공개 단계에 맞는 기사·댓글을 목록에서 고른다. 같은 소문 문구는 서로 다른 실제 결과에서도 사용할 수 있게 하여 문장 암기가 미래 가격의 정답이 되지 않도록 한다.

대표적인 사건 흐름은 다음과 같다.

| 단계 | 실제 호재를 일찍 잡은 경우 | 거짓 소문인 경우 |
| --- | --- | --- |
| 커뮤니티 게시 | 개발 성공을 암시하는 글, 아직 조용한 차트 | 근거가 빈약한 성공 주장 |
| 소문 확산 | 거래량과 관심이 서서히 증가할 수 있음 | 상승 없이 지나가거나 기대만으로 잠깐 상승 |
| 공식 뉴스 | 실제 성과 확인, 가격이 이미 오른 상태일 수 있음 | 회사 부인·정정 또는 실패 발표 |
| 이후 가격 | 추가 상승·횡보·차익 실현에 따른 하락 중 사건에 맞는 흐름 | 기대 소멸로 하락하거나 기존 가격 부근 유지 |

공식 보도만 나오고 사전 소문은 없는 사건, 실제 성과가 소문보다 작은 사건, 사실인데 이미 널리 알려진 사건도 섞는다. 모든 사건이 같은 단계와 같은 시간 간격으로 진행되지는 않는다. 소문의 진위와 별개로 군중 심리로 일시적인 가격 변화가 생길 수 있다.

예시 흐름은 모모바이오 주가 1,000에서 시작해 커뮤니티 소문이 등장하고, 확인 전 관심이 붙어 1,200까지 오른 뒤, 공식 발표 때 1,300이 되는 경우다. 커뮤니티 단계에서 매수한 플레이어는 큰 상승 구간에 참여할 수 있지만, 뉴스에서 처음 본 플레이어는 이후 추가 상승 여부를 판단해야 한다. 거짓 소문 분기에서는 잠깐 1,100까지 올랐다가 회사 부인 후 900으로 내려갈 수도 있다. 이 숫자는 연출 설명용 예시이며 고정 패턴이나 밸런스 수치가 아니다.

### 정보 탐색과 거래 시간

저녁 거래 전에는 현재까지 공개된 기사와 게시글을 읽고 관심 종목을 정한다. 세션 중에도 정해진 시장 시각에 새 글과 후속 기사가 공개된다. 출시 초안에서는 읽기 화면을 열면 시장 시계도 멈춰, 읽는 속도 때문에 손해를 보지 않도록 한다. 증권 앱으로 돌아와 거래 재개를 누르면 같은 시점에서 이어진다.

읽기 화면을 여는 동안에는 주문과 체결도 멈춘다. 새로고침·재열람·사이트 전환으로 시간이 흐르거나 다음 정보가 미리 공개되지 않는다. 정보 공개는 글을 읽은 횟수가 아니라 시장 시각을 기준으로 한다. 메뉴에서 멈추는 기존 규칙과 동일하게 적용한다.

종목 전환과 두 사이트 이용 기록은 유지한다. 관련 종목 바로가기, 관심 종목 저장, 읽은 글 표시와 최신 글 표시를 제공한다. 기사와 글의 목록은 게임 내 시각으로 정렬하고 과거 내용도 다시 확인할 수 있게 한다.

선반영을 보여줄 과거 차트와 과거 게시물은 새 게임 시작 때 함께 준비한다. 이후 알바·꾸미기·컷신 중에는 시장이 진행되지 않는다. 여러 날짜에 걸친 사건은 다음 거래 세션에서 이어지게 하며, 아직 열리지 않은 다음 단계의 정보는 보이지 않게 한다.

### 주식 플레이의 선택

뉴스만 보고 상대적으로 확인된 사건을 추적하거나, 커뮤니티에서 이른 단서를 찾아 도전하거나, 둘을 대조하다 관망하는 선택이 가능해야 한다. 읽은 글 수가 많다는 이유만으로 수익을 올려주는 방식은 사용하지 않는다.

종목별 뉴스와 게시물을 연결해 보되 정답을 자동 요약하는 신호는 제공하지 않는다. “기사는 좋지만 이미 크게 올랐다”, “추천은 많지만 원출처가 없다”, “소문 뒤 거래량이 붙었고 반박 근거도 있다” 같은 해석을 플레이어가 직접 할 수 있게 구성한다.

사건이 확인되거나 정정되면 후속 뉴스와 댓글에도 그 결과를 남긴다. 잘못된 거래 뒤에도 무엇이 사실이었고 무엇이 과장이었는지 돌아볼 수 있어야 한다. 정정이 나오기 전까지 모든 소문을 참·거짓으로 표시하지 않는다.

### 주변 인물의 정보 제공 확장

스토리를 넣을 때 편의점 동료, 단골, 친구 등이 자기 경험이나 들은 이야기를 전달할 수 있다. “요즘 그 음료 주문이 늘었어”처럼 인물이 실제로 관찰할 수 있는 범위의 정보부터 시작한다.

친밀도는 더 자세한 대화나 맥락을 여는 데 사용한다. 친밀도가 높다고 모든 제보가 맞거나, 정보를 들으면 해당 종목이 확정 상승하는 규칙은 두지 않는다. 인물도 오해하거나 오래된 정보를 전달할 수 있고, 이후 대화에서 결과에 반응할 수 있다. 이 기능은 현재 확정된 뉴스·커뮤니티 시스템 이후의 스토리 확장이다.

### 정보와 연계한 컷신 후보

| 컷신 가제 | 조건 초안 | 연출 |
| --- | --- | --- |
| 아무도 안 믿던 글 | 관련 소문을 읽은 뒤 공식 확인 전 매수하고, 같은 사건의 호재 확인 후 정한 기준 이상의 이익 실현 | 묻혀 있던 게시글을 다시 찾아보며 혼자 뿌듯해함 |
| 추천은 많았는데 | 거짓 소문 글을 읽은 뒤 매수하고, 관련 사건 정정 후 정한 기준 이상의 손실 확정 | 추천 수를 다시 보다가 조용히 사이트를 닫음 |
| 기사는 진짜였잖아 | 확인된 호재 뉴스 뒤 진입했지만 이후 손실 확정 | 기사와 차트를 번갈아 보며 억울해하다 진입 가격을 확인 |

컷신은 관련 글 열람·관련 종목 체결·사건 공개 시점·확정 손익이 연결될 때 판정한다. 우연히 글 하나를 읽고 전혀 다른 종목에서 손실을 낸 경우를 같은 조건으로 세지 않는다. 해당 글을 읽었다는 사실만으로 플레이어가 그 정보를 믿었다고 단정하는 대사는 피한다.

### 주식 기획의 검토 기준

- 뉴스에서 사실의 신뢰도와 이후 가격 상승 가능성이 구분되는가.
- 커뮤니티 추천 대부분이 큰 상승으로 이어지지 않으면서도, 드문 실제 기회가 존재하는가.
- 일찍 맞힌 소문이 공식 뉴스 이후 진입보다 큰 상승 구간을 제공하는가.
- 게시 시각·원출처·반박·차트로 판단할 여지가 있으며 특정 문구가 정답이 되지 않는가.
- 매수 여부나 글을 읽는 순서가 사건의 진위와 가격 방향을 바꾸지 않는가.
- 같은 소문·공식 기사·정정·차트가 하나의 사건으로 일관되게 연결되는가.
- 읽기 화면의 시간 정지와 거래 재개가 모든 종목에 동일하게 적용되는가.

## 고정 종목과 회차별 시장 구성

### 고정할 것과 무작위로 정할 것

| 고정 데이터 | 회차별 무작위 데이터 |
| --- | --- |
| 회사 ID, 회사명, 종목 코드·종목명, 업종과 사업 설명 | 사건이 배정되는 회사와 사건 종류·결과 |
| 사전 작성한 뉴스·게시글·댓글과 표시 조건 | 소문·공식 발표·후속 글의 공개 시각과 문구 선택 |
| 매매 규칙, 주문과 비용 계산 방식 | 추세, 변동성, 등락 폭, 시장 기대와 가격 반영 정도 |
| 스토리의 주요 구간과 선택지 | 어느 게임 날짜에 자산 구간에 도달하는지 |

고정 회사 목록을 통해 플레이어가 세계관을 익힐 수 있게 하고, “특정 날짜에 특정 회사를 사면 반드시 오른다”는 회차 공략은 성립하기 어렵게 한다. 모든 회사가 무조건 번갈아 성공하거나 실패하는 순서도 두지 않는다. 업종에 맞지 않는 사건은 배정하지 않는다.

무작위화는 반복 플레이에서 동일한 정답을 외우는 문제를 줄이기 위한 장치다. 숙련자가 판단을 개선해 다시 클리어하는 것은 허용한다. 플레이어가 잘한다는 이유로 상승을 취소하거나 수익을 강제로 빼앗는 보정은 넣지 않는다.

새 게임은 새로운 회차 시드로 시작한다. 진행 저장에는 회차 시드, 시장 시각과 상태, 난수 진행 상태, 이미 정해진 사건, 공개된 글과 표시 이력을 함께 보관한다. 불러오기·앱 전환·글 새로고침은 사건을 재추첨하지 않는다. 시장 난수와 문구·장식 선택 난수를 분리해 글을 더 읽거나 테마를 바꾼 것이 가격을 바꾸지 않게 한다. 자세한 시장 계산식과 각 결과의 확률은 아직 밸런스 설계 전이다.

### 사전 작성 콘텐츠의 선택

뉴스·커뮤니티·댓글은 플레이 중 AI로 새로 쓰지 않는다. 개발 중 충분한 문구를 준비하고, 플레이 중에는 조건에 맞는 항목을 선택하여 회사명·제품명 같은 자리표시자만 치환한다. 글 전문을 목록에 보관하며 화면마다 임의의 문장을 조합하지 않는다.

선택 순서는 **종목과 사건 확인 → 공개 단계 확인 → 사실·게시글 맥락에 맞는 후보 추림 → 최근 중복 제외 → 가중 선택 → 표시 이력 저장**으로 잡는다. 내부의 사건 결과·조건 태그·선택 가중치는 플레이어 화면에 보여주지 않는다.

공식 뉴스는 확인된 사실을 전달한다. 댓글은 긍정·부정 반응과 추측도 포함하지만, 아직 공개되지 않은 실제 결과를 먼저 아는 문장은 선택하지 않는다. 사건에 관한 반응 댓글은 해당 사건이 공개된 뒤 같은 사건에 연결된 게시글에만 달린다. 일반 댓글도 어울리는 게시글 ID 목록을 기준으로 골라 음식 글에 계약 정정 댓글이 붙는 상황을 줄인다.

글을 고르기 위한 가중치와 실제 호재 발생 확률은 구분한다. 콘텐츠의 수가 같다는 이유로 성공·실패 확률을 같은 값으로 두지 않는다. 커뮤니티가 맞아 큰 상승으로 이어지는 경우가 상대적으로 드물다는 기존 방향을 결과 가중치와 가격 반응 밸런스에서 유지한다.

초기 제안은 한 밤에 새 뉴스 2~3편, 커뮤니티 글 6~10편, 글별 댓글 2~4개 정도다. 이는 전체 라이브러리를 한꺼번에 보여주는 수량이 아니다. 재등장 금지 기간은 검토용 값이며, 후보가 부족하면 관련 없는 글을 넣기보다 글 수를 줄인다. 이전 사건 기록을 복사해 새 사건처럼 꾸미지 않는다.

현재 목록은 첫 콘텐츠 초안이다. 이 분량만으로 장기 회차의 반복 문제가 해결됐다고 간주하지 않는다. 다음 작성은 각 사건의 소문 변형, 가격·거래량 상황에 맞는 반응, 일상 대화와 댓글의 폭을 늘리는 순서로 진행한다. 특정 문장이 실제 결과를 노출하는지와 같은 글이 얼마나 자주 보이는지는 회차 시뮬레이션으로 확인한다.

JSON을 수정 가능한 기준 데이터로 두고 Markdown은 기획 설명과 작성 규칙에 사용한다. Unity 적용 전에는 JSON 문법, ID 중복·참조, 사건·기사의 연결, 회사명 치환과 댓글 맥락을 검증한다. 아직 시장 엔진이나 Unity 앱에 연결한 상태는 아니다.

## 컨디션과 투자 중 불이익

수면과 식사, 장시간 거래의 영향을 하나의 컨디션 게이지로 표현한다. 허기·피로·스트레스를 개별 관리하는 방식은 후속 검토로 둔다. 컨디션이라는 명칭은 확정하며, 아래 단계와 효과·회복 규칙은 비교할 제안이다.

핵심 선택은 **지금 쉬거나 돈을 써서 컨디션을 챙길지, 피곤한 상태로 더 거래할지**다. 컨디션은 주인공이 정보를 관찰하는 상황에 영향을 준다. 시장의 실제 가격이나 소문의 진위, 거래 손익 확률에는 영향을 주지 않는다.

### 권장 불이익 단계

| 단계 | 효과 초안 | 플레이어가 느끼는 불이익 |
| --- | --- | --- |
| 양호 | 정상 화면과 집중한 표정 | 거래에 집중할 수 있음 |
| 피곤 | 하품, 눈 비비기, 화면 가장자리 흐림 | 상태 악화의 예고, 핵심 정보는 읽을 수 있음 |
| 매우 피곤 | 가끔 짧은 눈 감김으로 차트 일부를 가림 | 짧은 구간의 움직임을 실시간으로 놓침 |
| 한계 직전 | 눈 감김이 더 길어지고 자주 발생 | 계속 거래할수록 관찰이 끊겨 회복과 휴식의 필요 증가 |
| 소진 | 시장 자동 일시정지와 회복·밤 종료 선택창 | 회복 수단을 쓰거나 그날 거래를 마쳐야 함 |

매우 피곤 단계의 눈 감김은 약 0.5~1초, 한계 직전은 약 1~2초를 비교 출발점으로 삼는다. 발생 빈도와 게이지 경계는 플레이 검증 뒤 정한다. 강한 화면 흔들림보다 눈꺼풀처럼 차트를 잠깐 가리는 연출을 우선한다.

눈 감김 도중에도 시장은 흐르지만, 주문 영역과 현금·보유 자산·현재가는 정확하게 유지한다. 이미 낸 주문도 기존 규칙에 따라 처리된다. 눈을 뜨면 실제 진행한 캔들이 정상적으로 남아 있어, 과거 차트를 다시 살필 수 있다. 짧은 관찰 공백이 불이익이며 과거 데이터가 영구 삭제되지는 않는다.

숫자와 캔들을 가짜 값으로 바꾸는 환각 효과는 기본 불이익으로 채택하지 않는 안을 권장한다. 숫자 잔상 같은 표현을 쓰더라도 읽어야 할 실제 값과 구별되게 한다. 주문 확인창에는 항상 실제 종목·수량·가격·금액을 표시한다. 주문 수량의 자동 변경, 클릭 무시, 의도하지 않은 매매, 주문 지연은 컨디션 효과로 넣지 않는다.

### 발생 예고와 시간 규칙

게이지에는 현재 단계와 다음 단계의 불이익을 표시한다. 처음 눈 감김이 생기기 전에는 “졸음 때문에 차트를 잠깐 놓칠 수 있어”라는 안내와 짧은 캐릭터 반응을 준다. 눈 감김 직전에도 눈꺼풀 연출로 예고한다.

눈 감김은 거래 중인 시장 시계를 기준으로 간격을 두고 발생하며 연속해서 겹치지 않는다. 뉴스·커뮤니티·일반 메뉴에서 시장이 멈추면 컨디션 소모와 효과 진행도 멈춘다. 메뉴를 여닫아 예정된 효과를 지우거나 발생 간격을 초기화할 수는 없다. 거래를 재개하면 남은 상태부터 이어진다.

컨디션 0에서 시장이 멈추는 동안에는 기존 주문 체결과 선물 청산 판정도 함께 멈춘다. 회복 후 같은 시점에서 재개하거나, 일반 밤 종료 규칙에 따라 정산과 컷신으로 넘어간다. 강제로 미래 시각으로 건너뛰거나 모든 자산을 매도하는 기능은 붙이지 않는다. 선물 도입 시 밤 종료의 포지션 처리 규칙은 별도로 정한다.

### 소모와 회복

| 수단 | 역할 초안 | 선택의 대가 |
| --- | --- | --- |
| 수면 | 다음 날 정상적인 알바와 기본 거래를 할 컨디션 회복 | 그날 거래 세션 종료 |
| 식사 | 일정량 회복, 일정 구간 컨디션 소모 완화 | 게임 내 화폐 사용, 같은 밤 반복 섭취 효과 제한 |
| 간식 | 소량 즉시 회복 | 회복량이 작음 |
| 에너지 음료 | 일정 구간 컨디션 감소를 일시적으로 억제 | 게임 내 화폐 사용, 연속 사용 효과 감소 |

소모는 기본 알바와 거래 세션 진행량을 기준으로 정하며, 실제 글을 읽는 속도나 매매 클릭 횟수로 계산하지 않는다. 수면으로 회복한 상태에서는 기본 알바와 정해진 길이의 거래를 무리 없이 경험할 수 있게 한다. 컨디션 하락이 본격적인 선택이 되는 시점은 장시간 거래나 수면 부족 상황으로 잡는다. 세션 길이·수면량 선택은 추후 확정한다.

에너지 음료는 수면을 영구 대체하지 않는다. 효과가 끝나면 정상적인 소모 속도로 돌아가는 단순한 방식부터 비교하며, 추가 반동으로 컨디션이 급락하는 규칙은 별도 검토로 둔다. 음료만으로 소진 상태를 회복할 수 있게 할지는 식사 회복량과 함께 결정한다.

손실 자체로 컨디션이 급격히 감소하는 규칙은 초기안에서 제외한다. 투자 손실·대출 이자·회복 비용이 연달아 겹쳐 복귀를 막지 않게 한다. 소진 후에도 무료 수면과 다음 날 편의점 근무는 가능해야 한다.

### 컷신과 캐릭터 표현

피곤할 때는 자세, 눈 밑 표현, 대사 길이와 말투를 바꾼다. 여유 있던 주인공이 “한 번만 더 보고 자자”라며 버티거나, 큰 수익을 내고도 졸려서 반응이 늦는 장면으로 갭을 표현한다.

수집 컷신 후보는 컨디션이 낮은 상태에서 거래를 마친 「차트보다 먼저 졸았다」, 손실 뒤 식사로 회복한 「수익보다 따뜻한 한 끼」, 피곤해서 일찍 거래를 마친 「오늘은 여기까지」 등이다. 특정 손실을 컨디션 탓이라고 단정하지 않고 실제 발생한 행동과 상태를 조건으로 쓴다.

### 검토 기준

- 플레이어가 게이지와 예고를 보고 언제 불이익이 생기는지 이해할 수 있는가.
- 낮은 컨디션에서 관찰 방해가 느껴지면서도 정확한 주문은 가능한가.
- 메뉴를 열거나 글을 읽는 것으로 컨디션 소모가 진행되거나 효과가 초기화되지 않는가.
- 수면으로 무료 복귀가 가능하고, 회복 아이템은 더 거래하기 위한 선택으로 느껴지는가.
- 컨디션 효과가 차트 판단보다 더 큰 무작위 손실 원인이 되지 않는가.

## 대출과 상환

자금이 부족한 플레이어는 저녁 거래 전에 대출을 선택할 수 있다. 알바로 천천히 복귀하거나, 빚을 지고 빠르게 재도전하는 선택이 생긴다. 대출은 자동으로 실행하지 않으며, 수입이나 투자 성공으로 집계하지 않는다.

초기 규칙 제안은 다음과 같다. 금리·한도·기간의 구체적인 수치는 경제 밸런스를 정할 때 확정한다.

| 항목 | 규칙 초안 |
| --- | --- |
| 대출 가능 시점 | 저녁 거래 시작 전, 사용 가능한 현금이 정한 기준보다 적을 때 |
| 대출 한도 | 초반 고정 소액 한도, 미상환 원금만큼 추가 가능 금액 감소 |
| 사전 표시 | 받을 금액, 현재 부채, 이자 방식, 상환일, 예상 상환액 |
| 이자 | 남은 원금에 게임 내 하루 단위 단리 적용, 일일 상한 적용 |
| 상환 | 결산에서 일부 또는 전액 상환, 만기에는 사용 가능한 현금 범위에서 자동 상환 |
| 연체 | 신규 대출 제한, 알바 수입 일부를 상환에 사용하며 복구 |
| 복귀 보장 | 연체 중에도 편의점 근무 가능, 알바 수입 일부는 다음 투자금으로 남김 |

신규 대출은 다음 날부터 이자가 발생하고, 같은 날 대출과 전액 상환만 반복해도 도전과제가 열리지 않게 한다. 대출과 상환은 플레이어가 이해하기 쉬운 하나의 게임 내 대출 창구로 시작한다.

선물 거래에 빌린 돈을 투입하면 강제 청산 뒤에도 대출은 남는다. 거래에 배정한 금액을 넘는 추가 거래 손실은 발생하지 않지만, 빌린 원금과 정해진 이자는 상환해야 한다. 이 관계를 대출·주문·결산 화면에 동일하게 표시한다.

연체 장면은 캐릭터의 자조나 생활 코미디로 표현한다. 빚이 늘기만 하는 막다른 진행이 되지 않도록 최대 이자 누적액과 알바 수입의 상환 비율을 함께 조정한다. 구입한 집과 가구를 자동으로 압류하는 규칙은 초안에 넣지 않는다.

## 밤 종료 컷신과 수집

### 컷신의 역할과 형식

컷신은 그날 플레이의 감정적 결말이다. 캐릭터가 수익에 들뜨거나, 청산 뒤 멍해지거나, 대출 상환 후 안도하는 장면으로 숫자의 결과를 보여준다. 외형과 반응의 갭을 구체적으로 표현하는 주요 콘텐츠로 사용한다.

초기 형식은 전용 2D 일러스트에 표정 변화·카메라 이동·효과음·짧은 대사를 더하는 방식으로 제안한다. 처음부터 모든 장면을 영상이나 풀 애니메이션으로 만들지는 않는다. 특별 컷신은 약 10~25초, 조건 미달 시 기본 연출은 약 2~4초를 잠정 목표로 한다.

### 해금과 재생 흐름

1. 밤 거래를 끝내면 해당 밤의 거래·강제 청산 기록과 누적 달성을 집계한다.
2. 결산에서 그날의 이자와 상환을 반영하고, 상환 관련 달성도 확정한다.
3. 조건을 충족한 미수집 컷신을 모두 해금하고 저장한다.
4. 여러 장면이 해당하면 대표 컷신 하나를 재생한다. 다른 새 장면은 해금 목록에서 즉시 다시 볼 수 있다.
5. 특별 조건이 없다면 짧은 기본 취침 연출을 재생하는 안을 기본 제안으로 둔다. 연출 생략안과 최종 비교한다.

대표 장면은 미감상 신규 장면을 우선하고, 그 안에서는 서사 진행에 필요한 장면, 강제 청산처럼 큰 사건, 일반 수익·손실 반응 순으로 고른다. 같은 우선순위에서는 고정된 순서를 사용한다. 조건을 달성했는데 무작위 추첨 때문에 해금이 누락되는 구조는 쓰지 않는다.

예를 들어 같은 밤에 강제 청산과 첫 수익 조건을 모두 달성했다면 두 장면을 모두 해금하고 청산 장면을 대표로 보여준다. 이때 한 장면의 대사가 그날 전체 결과와 모순되지 않도록 “오늘 거래는 전부 망했다” 대신 “그 포지션만큼은 너무 무리했어”처럼 해당 사건에 반응한다.

이미 수집한 장면도 상황에 맞으면 반복 재생할 수 있으며, 설정에서 본 컷신 자동 넘기기와 기본 연출 생략을 지원한다. 최초 장면도 수동으로 넘길 수 있다. 해금 여부와 실제 감상 여부를 구분하여 갤러리에서 미감상 표시를 제공한다.

### 컷신 후보와 조건 예시

아래 조건은 아이디어를 비교하기 위한 예시다. 금액·비율·일수는 아직 확정하지 않는다.

| 컷신 가제 | 조건 예시 | 장면과 갭모에 |
| --- | --- | --- |
| 오늘 디저트는 두 개 | 거래가 있었던 밤에 일일 거래 실현 순손익이 처음으로 양수 | 냉정하게 결산하던 주인공이 디저트 메뉴 앞에서 진지하게 고민 |
| 표정 관리 실패 | 정해진 최소 이익액과 높은 일일 수익률을 함께 달성 | 침착한 척하다 혼자 침대 위에서 기뻐함 |
| 화면은 꺼도 현실은 남는다 | 첫 선물 강제 청산 발생 | 노트북을 천천히 닫았다가 다시 열어 잔액을 확인 |
| 빌린 돈의 무게 | 첫 대출을 받고 그날 거래를 한 번 이상 체결 | 평소에는 쉽게 쓰던 금액을 두고 주문 버튼 앞에서 망설임 |
| 내 돈으로 돌아온 밤 | 이전 날짜부터 남아 있던 대출과 이자를 전액 상환 | 상환 완료 화면을 보고 소박한 간식으로 자축 |
| 마지막에는 웃었다 | 같은 밤에 강제 청산을 겪고도 일일 거래 실현 순손익이 양수 | 지친 표정으로 계산하다 결과를 보고 작은 승리 포즈 |
| 내일도 출근 | 거래 종료 시 투자 가능한 자산이 기준 이하이고 대출도 남음 | 편의점 근무복을 꺼내 정리하며 알람을 다시 확인 |
| 아무것도 안 하는 용기 | 거래 세션을 지켜보고 한 번도 매매하지 않은 채 종료 | 주문창을 닫고 편안하게 차를 마심 |
| 조금씩 쌓인 자신감 | 거래가 있었던 여러 밤에 연속으로 실현 순이익 달성 | 매일 적던 가계부를 보며 스스로 대견해함 |
| 다음 집에서는 | 밤 종료 시 이사 목표에 필요한 순자금 달성 | 평소 보던 집 사진 대신 실제 이사 계획을 적음 |

고액 수익률 장면에는 최소 이익액 조건을 함께 둬 극소액 거래로 달성되는 문제를 줄인다. 이사 자금은 보유 현물의 평가액과 부채를 반영해 정의하되, 실제 구매는 사용할 현금으로 처리한다. 미실현 이익 전용 장면을 추가한다면 실현 수익 장면과 별도 조건으로 둔다.

### 수집 화면

집의 앨범이나 메인 메뉴에서 컷신 갤러리를 연다. 해금한 장면의 썸네일, 제목, 달성 조건, 최초 달성일, 감상 여부를 확인하고 다시 재생할 수 있다. 성공·실패·대출·생활 등으로 찾아볼 수 있게 한다.

미해금 장면은 실루엣과 짧은 힌트를 기본으로 보여준다. 조건 공개 설정을 두어 수집을 목표로 하는 플레이어는 정확한 조건도 확인할 수 있게 한다. 핵심 스토리의 반전이 있는 장면만 별도 비밀 항목으로 다룬다.

컷신 수집 기록은 회차의 자금·부채와 분리해 저장한다. 새 게임이나 이전 진행 저장 불러오기로 이미 얻은 컷신이 사라지지 않도록 한다. 장면별 사건 기록과 달성 결과를 저장해 중단 후 다시 시작해도 중복 보상이 발생하지 않게 한다.

수집은 이야기와 감상 보상으로 시작한다. 일부러 손실을 반복해야 거래 성능이 좋아지는 보상은 붙이지 않는다. 기본 취침 연출은 수집 달성률에서 제외한다.

### 컷신 판정을 위한 기록 기준

- 일일 거래 실현 순손익은 해당 밤에 확정된 매매 손익에서 거래 비용을 뺀 값이다. 이전 날짜에 산 현물을 오늘 매도한 손익도 오늘 실현한 것으로 기록한다.
- 알바 수입, 대출 입금, 원금 상환, 가구 구매는 거래 수익에서 제외한다. 이자는 결산 비용으로 별도 표시한다.
- 일일 수익률용 기준 자금은 거래 시작 직전, 대출까지 반영한 현금과 보유 현물 평가액의 합으로 고정한다. 기준이 0이면 수익률 조건은 판정하지 않는다.
- 투자 가능한 자산은 현금과 보유 현물 평가액, 순금융자산은 여기서 미상환 원금과 발생 이자를 뺀 값으로 구분한다.
- 선물 강제 청산은 별도 사건으로 기록하며, 직접 매도나 자발적 포지션 종료를 청산 컷신 조건으로 세지 않는다.
- 하루 도중 일어난 청산 사건은 밤 종료까지 보존한다. 이후 수익을 내도 사건 자체가 취소되지 않는다.

## 성공을 보여주는 집과 UI

### 집의 성장

집은 거래를 시작하고 하루를 끝내는 주요 화면이다. 독립된 주택 시뮬레이션 대신, 한눈에 변화가 보이는 2D 방 화면으로 시작한다. 책상의 컴퓨터를 누르면 가상 OS 바탕화면, 문을 누르면 알바로 이동한다. 침대에서 하루를 마칠 때 미완료 밤 거래가 있으면 결산 흐름을 먼저 거쳐 다음 날로 이동한다.

| 성장 단계 예시 | 공간과 소품 | 주인공의 변화 |
| --- | --- | --- |
| 작은 자취방 | 낡은 책상, 노트북, 단출한 침대 | 좁은 책상 위에서 간식을 치우고 거래 시작 |
| 정돈된 원룸 | 새 의자, 모니터, 수납장, 식물 | 편안한 자세와 방을 자랑하는 대사 |
| 넓은 집 | 별도 작업 공간, 큰 창, 취향에 맞는 가구 | 일과 휴식 공간을 나누는 생활 연출 |
| 목표 주거 공간 | 전망 좋은 집 또는 취향을 완성한 개인 공간 | 목표 달성 이벤트와 엔딩 장면 |

집은 배경 한 장을 통째로 바꾸는 것과 가구를 하나씩 바꾸는 것을 결합한다. 작은 구매도 바로 화면에서 보이고, 이사는 큰 성취로 느껴지게 한다. 첫 시제품은 같은 방 안의 가구 교체만 구현한다.

이사 가격은 게임 내 주거 등급을 올리는 일회성 비용으로 단순화한다. 주택 대출, 임대차 계약, 부동산 가격 변동은 초기 범위에 넣지 않는다.

### 거래 UI의 성장

처음에는 소박한 개인용 컴퓨터 바탕화면에서 시작한다. 파스텔 톤을 유지하면서 성장에 따라 배경화면·창 테두리·앱 아이콘·알림음과 거래 확정 효과가 바뀐다. 여러 모니터와 좋은 장비는 집에서 보이는 성장으로 표현하며, 앱마다 정보를 분리하는 구조는 유지한다.

**기본 차트 가독성과 필수 거래 기능은 처음부터 제공한다.** 성공 보상으로 주문 정확도, 정보 지연, 수익 확률이 개선되는 방식은 쓰지 않는다. 낮은 주거·UI 단계에서도 글씨가 선명하고 거래가 편해야 한다. 컨디션 저하의 일시적인 관찰 방해는 UI 테마 등급과 구분한다.

첫 UI 테마 교체는 게임 내 실현 수익 누적 목표를 달성하면 무료로 해금하는 방식으로 제안한다. 해금한 테마는 자유롭게 다시 선택할 수 있다. 집의 장비 구매는 방에 보이는 외형을 바꾸며, 거래 성능은 동일하게 유지한다.

### 자금과 생활 성장의 관계

가구와 이사에는 현금을 사용한다. 구매 화면에는 가격과 구매 후 남을 투자금을 함께 보여준다. 집을 꾸민 뒤 투자금이 줄어드는 것은 플레이어가 이해하고 선택하는 비용이다.

계좌 자산과 생활 성장 기록은 분리한다. 계좌에는 현금과 보유 투자 자산을 표시하고, 생활 기록에는 소유한 가구·주거 단계·달성 목표를 남긴다. 집에 쓴 돈을 거래 손실로 표시하지 않는다.

구매한 가구와 해금한 테마는 거래 손실로 자동 회수되지 않는다. 성공 이후의 손실이 모든 성취를 지워버리지 않도록 한다. 첫 시제품에서는 가구 재판매를 제외하고, 구매는 한 번만 가능하게 한다.

## 미소녀 주인공과 갭모에

주인공 초안은 귀여운 소품과 소소한 소비를 좋아하지만, 돈 앞에서는 계산이 빠르고 자기 원칙이 있는 성인 여성이다. 귀여운 외형에 전문 용어만 붙이기보다, 평소 취향과 거래할 때의 태도 차이를 표정·동작·대사로 보여준다.

| 상황 | 연출 예시 |
| --- | --- |
| 알바 시작 | 밝은 표정으로 손님을 맞이하면서 퇴근 후 살 가구를 떠올림 |
| 매수 직전 | 리본과 인형으로 꾸민 책상에서 표정이 진지해짐 |
| 작은 이익 확정 | “오늘 디저트 값 확보.”라며 조용히 기뻐함 |
| 큰 손실 확정 | 잠깐 굳었다가 “내일 알바는 지각하면 안 되겠다.”라며 마음을 추스름 |
| 새 의자 구매 | “차트는 그대로인데 허리는 행복하네.”라며 앉아 봄 |
| 목표 금액 도달 | 평소의 침착함을 잃고 이사할 방 사진을 반복해서 확인 |

대사는 거래가 확정된 뒤나 결산 때 짧게 출력한다. 주문 버튼과 차트를 가리지 않고, 반복 빈도를 제한하며, 끄기 설정을 제공한다. 주인공의 성격은 플레이어의 매매 선택을 비난하거나 특정 전략을 강요하지 않는다.

옷과 헤어, 휴식 동작, 집에서의 생활 이벤트는 후속 보상으로 확장할 수 있다. 처음에는 주인공 한 명의 표정과 반응에 집중한다.

## 아침 알바 미니게임

첫 알바는 편의점 근무로 확정한다. 미니게임 초안은 손님이 가져온 상품의 바코드를 스캔하고, 결제 방식에 맞춰 계산한 뒤 손님을 응대하는 흐름이다. 기본급은 끝까지 플레이하면 받고, 빠르고 정확한 처리에는 근무 보너스가 붙는다. 상품 진열과 재고 정리는 이후 확장 요소로 둔다.

입력 실수로 투자 복귀가 막히지 않도록 기본급만으로도 다시 거래할 수 있게 한다. 처음에는 난도를 낮추고, 능숙해지면 짧은 시간에 근무 보너스를 더 얻는 정도로 차이를 준다.

알바가 매일 같은 의무로 느껴지지 않는지 확인한다. 반복 문제가 확인되면 숙련 후 단축 근무나 낮은 수입의 간편 근무를 검토한다. 여러 알바와 별도의 숙련 트리는 첫 시제품 이후로 미룬다.

## 실패와 복귀

투자금을 잃어도 알바는 계속할 수 있다. 무료 알바 진입과 기본급으로 복귀하거나, 한도가 남아 있다면 대출을 선택할 수 있다. 빚을 자동으로 추가하거나 즉시 게임오버 처리하지 않는다. 강제 청산과 손실도 조건에 맞는 컷신과 회복 이야기로 연결한다.

결산은 알바 수입, 거래 실현 손익, 보유 자산 평가 변화, 생활 구매를 구분해서 보여준다. 플레이어가 계좌의 변화가 어디에서 왔는지 이해할 수 있어야 한다.

생활 상태는 컨디션 하나로 다루며 수면·식사·음료와 거래 중 불이익을 검토한다. 별도의 생활비·허기·스트레스 게이지는 후속 검토로 둔다. 컨디션 소진과 연체가 겹쳐도 무료 수면과 알바를 통해 복귀할 수 있도록 한다.

## 목표와 보상

초반에는 첫 거래, 첫 수익 확정, 첫 가구 구매, 첫 UI 테마 해금처럼 가까운 목표를 제시한다. 중반부터는 방 완성, 더 큰 집으로 이사, 개인 목표 자산 달성으로 확장한다.

장면별 조건 달성과 컷신 앨범 완성이 별도의 도전 목표가 된다. 특정 장면만 찾아 도전하거나, 한 회차에서는 자산과 집 성장을 우선할 수 있다.

정식 버전의 성공은 자산 금액과 생활 목표를 함께 반영한다. 단기 수익률 순위만으로 평가하지 않고, 자신이 원하는 집을 완성하는 것도 하나의 엔딩 조건으로 삼는다. 엔딩 후에도 거래와 꾸미기를 계속할 수 있는 진행을 검토한다.

첫 플레이의 초반 2~3일 안에 적어도 하나의 눈에 보이는 보상을 살 수 있도록 가격을 조정한다. 이 목표는 알바 기본급만으로도 도달 가능하게 하고, 큰 이사 목표에서는 투자 성과가 진행 속도에 영향을 주게 한다.

## 자산 구간에 따른 스토리 분기

투자로 자금을 쌓아 특정 자산 구간에 도달하면 새 챕터와 선택지가 열리는 구조를 제안한다. 자산은 이야기의 진입 조건이고, 어느 이야기를 선택할지는 플레이어가 정한다. 돈만 늘면 자동으로 하나의 결말에 도달하는 방식보다 생활 목표와 인물 관계를 선택할 여지를 둔다.

| 구간 가제 | 이야기의 변화 | 선택 예시 |
| --- | --- | --- |
| 처음 생긴 여유 | 생존을 위한 알바와 투자에서 작은 목표를 고르는 단계 | 작은 생활 개선 / 다음 목표 준비 |
| 자리를 잡은 일상 | 안정된 생활을 유지할지 환경을 바꿀지 고민 | 익숙한 일상 / 새로운 생활 |
| 넓어진 선택지 | 투자 외의 삶과 더 큰 도전 사이에서 우선순위 선택 | 주변 사람과의 시간 / 더 큰 목표 |
| 내가 선택한 성공 | 쌓아온 선택에 따른 개인 목표와 엔딩 | 생활 목표 완성 / 투자 여정 계속 |

이는 본편 줄거리 확정이 아닌 구간 구조의 초안이다. 회사·시장의 결과는 회차마다 달라져도 주요 스토리 구간과 선택지는 유지한다. 선택에 따른 대사·컷신·관계 변화를 만들고, 다음 주요 챕터에서 다시 합류하는 구성을 우선해 분기 수가 끝없이 늘어나지 않게 한다. 마지막 구간에서 그동안의 선택을 반영한 엔딩을 검토한다.

### 자산 판정과 진행 유지

진입 기준은 우선 **결산 시 순금융자산과 누적 거래 실현 순손익**을 함께 사용하는 안으로 잡는다. 순금융자산은 현금과 보유 현물 평가액에서 미상환 원금과 발생 이자를 뺀 값이다. 누적 거래 실현 순손익에는 거래 비용을 반영하며 대출·알바 수입은 포함하지 않는다. 실제 필요한 금액과 최소 순이익은 아직 정하지 않는다.

대출금이 들어오면 현금과 부채가 함께 늘어나므로 대출만으로 이야기가 열리지 않는다. 투자 성공을 요구하는 구간에는 양수의 최소 누적 거래 순이익 조건을 둔다. 이미 구매한 집·가구는 생활 달성 기록으로 따로 인정하고, 해금된 스토리는 이후 구매나 손실 때문에 취소하지 않는다.

판정은 밤 결산의 이자·상환 반영 후, 새로운 가구·집 구매 전에 한 번 수행한다. 새 구간이 열리면 그날의 대표 컷신보다 스토리 장면을 먼저 보여주는 안으로 잡는다. 같은 날 달성한 일반 컷신도 모두 해금하고 갤러리에서 볼 수 있게 한다. 거래 도중에는 이야기로 화면을 강제로 가리지 않는다.

한 번에 여러 구간의 자산 조건을 넘으면 앞선 필수 장면과 선택부터 진행한다. 큰 수익을 내서 자산이 뛰어도 챕터를 건너뛰지 않으며, 남은 구간은 이후 결산에서 당시 조건을 다시 확인해 순서대로 연다. 열려 있는 구간과 선택 기록은 회차 저장에 보관한다.

컷신 수집은 회차를 넘어 유지하지만, 새 게임의 스토리 진행과 자산은 새로 시작한다. 다른 선택과 시장 상황을 경험하며 재도전하는 동기를 만든다.

## 첫 시제품 범위

현재는 컨셉을 더 정하는 단계다. 아래 시제품 범위는 잠정안이며, 개발 착수 전에 컷신 목록·대출 규칙·선물 강제 청산 체험의 포함 범위를 먼저 정한다.

전체 콘텐츠에 앞서 7일 정도 반복해서 즐길 수 있는 짧은 플레이를 구상한다. 투자 결과가 집·UI 변화와 조건부 컷신으로 이어지는지 확인한다. 강제 청산이 핵심 장면으로 확정되면 최소한의 선물 거래와 청산 규칙도 첫 검증 범위에 포함한다.

| 영역 | 포함 범위 |
| --- | --- |
| 주인공 | 1명, 기본 표정 4종, 상황 반응 대사 |
| 집 | 방 배경 1개, 교체 가능한 가구·장비 3개, 저장되는 구매 상태 |
| 컴퓨터 | 가상 OS 바탕화면, 클릭 실행 아이콘, 작업 표시줄, 앱 전환·최소화·닫기와 상태 유지 |
| 앱 구성 | 증권·인터넷을 기본 분리, 금융·앨범·설정의 구체적인 진입 구성 확정 |

| 컨디션 | 단일 게이지, 단계별 예고·관찰 방해, 수면·회복 수단의 검증 범위 확정 필요 |

코인, 다양한 선물 상품, 이사할 여러 집, 자유로운 가구 배치, 다수의 알바, 의상 수집, NPC 관계 시스템은 이후 확장 범위다. 첫 집의 가구는 정해진 자리에 교체하는 방식으로 구현한다.

## 첫 시제품의 확인 기준

- 플레이어가 도움 없이 차트를 확인하고 수량을 정해 첫 매수와 매도를 완료할 수 있다.
- 같은 가격 데이터가 캔들, 현재가, 체결, 보유 자산 평가에 일관되게 반영된다.
- 거래와 가구 구매 후 현금이 정확히 변하고, 불러오기 후에도 자금과 구매 상태가 유지된다.
- 투자금을 전부 잃은 경우에도 다음 날 알바를 통해 거래에 복귀할 수 있다.
- 첫 가구 구매 전후의 방을 보고 무엇이 좋아졌는지 바로 구분할 수 있다.
- 기본 UI와 해금 UI 모두 차트와 주문 정보가 읽기 쉽다.
- 플레이어가 다음 날을 진행하고 싶은 이유를 거래 기회나 다음 생활 목표로 설명할 수 있다.
- 같은 밤에 여러 컷신 조건을 충족하면 모두 해금되고 대표 장면만 자동 재생된다.
- 조건 미달, 이미 본 장면, 미감상 장면에서 각각 정한 기본 연출·자동 넘기기 규칙이 적용된다.
- 대출을 받은 금액이 수익 컷신 조건에 포함되지 않고, 강제 청산 후에도 부채가 일관되게 남는다.
- 새 회차에서도 컷신 수집 기록은 유지된다.
- 집에서 컴퓨터를 열면 바탕화면이 나오고, 아이콘을 눌러 증권·인터넷에 각각 진입할 수 있다.
- 증권 앱에 뉴스·커뮤니티·대출·회복·수집 상세가 한꺼번에 표시되지 않는다.
- 앱을 전환하거나 창을 닫아도 거래 상태와 읽던 내용이 유지되며, 시장 진행·정지 상태가 분명하다.
- 파스텔 배경에서도 본문·숫자·차트 눈금과 주문 버튼이 읽기 쉽다.
- 새 회차에서는 같은 회사의 사건·시점·차트가 달라지고, 같은 저장을 불러오면 진행 상태가 유지된다.
- 뉴스·댓글은 실제 사건과 공개 단계에 맞으며, 새로고침이나 글 선택이 가격 난수를 바꾸지 않는다.
- 대출만으로 자산 스토리 구간이 열리지 않고, 해금한 이야기는 손실이나 생활 구매로 취소되지 않는다.

## 폰트와 출시용 리소스 관리

최종 목표는 Steam 출시다. 그림·폰트·음원·효과음·플러그인은 리소스별로 공식 출처와 이용 조건을 확인하고 `리소스 관리대장.md`에 등록한다. 원본과 이용 조건 증빙은 `ThirdParty`에 보관하고, 사용 파일은 `Assets`에 배치한다. 실제 게임 크레딧과 배포 패키지에 필요한 고지를 포함한다.

첫 UI 폰트 후보는 경기천년제목 Light·Medium·Bold다. 블루 아카이브 UI 같은 인상을 참고하되, 해당 게임에서 추출한 파일을 쓰지 않고 경기도 공식 배포본을 사용한다. 실제 블루 아카이브 사용 서체에 대한 공식 확인을 의미하지 않는다.

2026년 11월 25일 확인한 경기도 공식 페이지에는 무료 이용과 프로그램에 탑재한 배포가 허용되어 있으며, 폰트 자체의 유료 판매·양도는 금지되어 있다. 원본 ZIP·페이지 HTML·이용 조건 발췌·파일 해시를 보관했다. 상세 내용은 `ThirdParty/Fonts/Gyeonggi/README.md`를 따른다.

Bold는 제목·버튼·주요 금액, Medium은 뉴스·커뮤니티·일반 본문, Light는 큰 보조 문구에 우선 비교한다. 원화 기호 U+20A9가 없어 금액은 우선 `1,250,000원` 형식으로 표시한다. 최종 채택은 Unity 실제 화면에서 가독성을 확인한 뒤 정한다.

## 후속 기획 순서

먼저 주인공의 성격과 작품의 분위기, 첫 수집 컷신 목록, 대출과 실패의 강도를 정한다. 조건 미달 시 기본 장면을 보여줄지와 강제 청산을 첫 플레이에 언제 소개할지도 결정한다.

주식은 작성한 회사·사건·글 목록을 바탕으로 정보 공개 속도, 한 밤의 읽기 분량과 무작위 배정 규칙을 구체화한다. 확률·등락 폭·거래 비용은 사건과 차트를 함께 검토하며 조정한다. 자산 스토리 구간의 금액과 첫 장면을 정하고, 주변 인물 제보는 스토리 단계에서 별도로 정한다.

다음 화면 시안은 파스텔 톤의 집, 컴퓨터 바탕화면, 증권 앱, 브라우저의 뉴스·커뮤니티를 각각 나누어 만든다. 초기 통합 투자 화면은 기능 참고로만 사용하고, 한 창에 모든 시스템을 배치하는 구조는 교체한다.

컨셉이 정해지면 시작 방과 성장 모습, 앱별 화면, 컷신 연출을 설계하고 시제품 제작 범위를 확정한다. 이후 7일 플레이로 투자 판단, 컷신 발견, 생활 성장, 대출 복구가 다음 밤의 동기가 되는지 확인한다.
