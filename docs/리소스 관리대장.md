## 리소스 추가 기준

1. 가능하면 제작자 또는 공식 배포처에서 받는다.
2. 리소스별로 상업적 이용과 게임 내 배포 조건을 확인하고, 페이지와 동봉 라이선스를 보관한다.
3. 무료 다운로드만 가능하고 게임 포함 배포가 확인되지 않은 리소스는 출시 에셋으로 넣지 않는다.
4. 원본 파일은 `ThirdParty`에 보관하고, 게임용 파일은 `Assets` 아래에 배치한다.
5. 수정·변환한 경우 원본과 별도로 변경 내용 및 파생 파일 경로를 기록한다.
6. 크레딧 문구와 배포에 필요한 라이선스를 `THIRD_PARTY_NOTICES.txt` 및 리소스별 기록에 반영한다.
7. 출시 빌드에서 실제 사용 에셋과 고지 파일을 대조한다. 제거한 후보는 사용 목록에서 제외하고 이력은 남긴다.

## 출시 전 남은 확인

- 최종 폰트 채택과 Unity TextMeshPro 렌더링·한국어 누락·숫자 가독성 확인.
- 실제 출시 때 원 배포처의 최신 이용 조건과 보관한 조건 비교.
- 게임 크레딧에 출처 표시, 최종 배포 패키지에 고지와 관련 이용 조건 포함.
- 사용자 제공 컨셉 이미지의 제작 경위 및 출시 사용 권리 확인.

현재 등록은 확인한 폰트와 기존·생성 참고 이미지를 대상으로 한다. 이후 그림·음원·효과음·플러그인도 같은 기준으로 등록한다.
