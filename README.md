# 두근두근 트레이딩

아침에는 편의점 알바로 투자금을 벌고, 밤에는 플레이어가 직접 정보를 읽고 매매하는 2D 투자·생활 게임입니다. 투자 결과는 주인공 윤서하의 생활 변화, 이야기 분기, 수집 가능한 컷신으로 이어집니다. 최종 목표는 Steam 출시입니다.

기획서, 콘텐츠 데이터, 화면·캐릭터 컨셉과 첫 폰트 후보에 이어 **Unity MVP**와 첫 아트 후보(하루 루프 전체 플레이 가능)를 추가했습니다. 화면은 씬의 uGUI 오브젝트라 Scene 뷰에서 옮기고 Inspector 에서 고치며, 수치·문구·바뀌는 이미지는 `Assets/Resources/GameConfig.asset` 에서 고칩니다.

## Unity MVP 실행과 편집

1. Unity Hub 에서 이 폴더를 열고(Unity 6.3 LTS) `Assets/Scenes/Main.unity` 를 엽니다. 처음 열면 에디터 스크립트가 GameConfig 에셋과 씬 UI 를 자동으로 만듭니다 (메뉴 **StockGame ▸ UI 만들기**와 같음).
2. 플레이(▶)를 누르면 타이틀부터 시작합니다.
3. 편집: 메뉴 **StockGame ▸ 화면 보기**로 화면을 고르고 Scene 뷰에서 배치를 바꿉니다. 수치는 **StockGame ▸ 설정 에셋 열기**, 뉴스·게시글은 **StockGame ▸ 콘텐츠 편집기**. 자세한 방법은 [config/README.md](config/README.md).

| 구현 범위 | 내용 |
| --- | --- |
| 하루 루프 | 집 → 편의점 알바 미니게임 → 가상 OS 컴퓨터 → 결산·상환 → 스토리 구간 → 컷신 → 잠자기 |
| 증권 앱 | 3종목, 1·5·15분 캔들과 거래량, 휠 확대·드래그, 평균 매입가선, 기사 시점 표시, 시장가 매수·매도, 보유·내역 |
| 시장 | 회차 시드, 사건 먼저 배정 → 소문·공식·후속 기사와 가격 연결(선반영·기대감·차익 실현), 증권 앱이 전면일 때만 시간 진행 |
| 브라우저 | 뉴스·커뮤니티 사이트, `data/` 사전 작성 글을 공개 단계·쿨다운·가중치로 선택, 사건 공개 후에만 사실 댓글 |
| 금융 앱 | 시작 부채 10억과 추가 투자 대출 분리, 이자·만기·연체·알바 수입 상환 |
| 컨디션 | 시장 틱 기준 소모, 가장자리 흐림·눈 감김(차트만 가림), 간식·식사·음료, 소진 시 정지 |
| 컷신·성장 | 조건 기반 동시 해금·대표 재생, 회차를 넘는 갤러리, 가구 구매·배치, 수익 목표 테마 해금 |
| 진행 보조 (1차) | 1일차 오늘 할 일, 첫 결산 반응·일상 장면, 결산 복기, 60분 연장 거래, 휴식·점장 만남, 생활 진척 첫 구간 |
| 편의 | 저장·불러오기, 튜토리얼, F1 편집 안내, F5 다시 읽기, F12 디버그 |

첫 MVP 아트 후보를 연결했습니다. 서하 6표정, 성인 여성 손님 4명과 시트, 배경·가구·상품·OS 아이콘을 포함합니다. [에셋 목록과 제작 기록](docs/mvp_assets_v001.md)을 참조하세요. 경제 수치는 시제품 검증용 임시값이며 외형 승인·출시 권리 확인과 7일 밸런스 검증은 별도입니다.

## 폴더 구성

| 폴더 | 내용 |
| --- | --- |
| `Assets/` | 게임 코드(`Scripts`), 씬(`Scenes/Main.unity`), 설정 에셋(`Resources/GameConfig.asset`), 폰트·UI 그림(`Art`) |
| `config/` | GameConfig 를 처음 만들 때 쓴 원본 JSON과 편집 안내 (실행 중에는 읽지 않음) |
| `data/` | 회사·사건·뉴스·커뮤니티·스토리 구간 JSON |
| `docs/` | 기획, 에셋 규칙, 캐릭터 및 화면 컨셉 |
| `ThirdParty/` | 폰트 원본, 참고·생성 자료, 출처와 이용 조건 증빙 |
| `tools/` | 콘텐츠 검증과 제작 보조 도구 |

## 콘텐츠 검증

프로젝트 루트에서 Python으로 실행합니다. 별도의 Python 패키지가 필요하지 않습니다.

```sh
python tools/validate_content_catalogs.py
python tools/validate_config.py
```

첫 번째는 `data/`의 JSON 문법, ID와 참조, 콘텐츠 표시 조건, 치환 문자열, 스토리 순서를, 두 번째는 `config/`의 문법·이미지 키·조건식 stat 이름·슬롯 참조를 확인합니다. Unity 플레이 검증을 대신하지 않습니다.

## Git 관리 기준

기획서·JSON·사용 에셋·출처 기록을 함께 버전 관리합니다. Unity의 `Library`, `Temp`, 빌드 결과와 개인 설정은 `.gitignore`로 제외합니다. Unity가 생성한 소스 에셋의 `.meta` 파일은 함께 커밋합니다.

리소스 추가 전 [에셋 생성 규칙](docs/에셋%20생성%20규칙.md)과 해당 배포처의 조건을 확인합니다. 외부 리소스와 참고 이미지의 권리·배포 조건은 파일별 기록과 [서드파티 고지](THIRD_PARTY_NOTICES.txt)를 따릅니다. 컨셉 이미지를 출시 승인된 에셋으로 간주하지 않습니다.
